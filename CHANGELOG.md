# Changelog

Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

O formato é baseado em [Keep a Changelog](https://keepachangelog.com/pt-BR/),
e este projeto adere a [Semantic Versioning](https://semver.org/lang/pt-BR/).

## [1.0.0] - 2026-05-13

### Adicionado
- ✨ Interface React profissional com TypeScript
- 🎸 Visualização gráfica do braço do violão com SVG
- 🔢 Cálculo de posições de trastes em escala temperada
- 📊 Exibição detalhada de medições e espaçamentos
- 🎯 Suporte a diferentes escalas e quantidades de trastes
- 📡 API REST em Clojure com endpoints GET e POST
- 🔄 Proxy Vite para comunicação Frontend/Backend
- 🛡️ CORS habilitado para requisições cross-origin
- 📱 Design responsivo para dispositivos móveis
- 📄 Documentação completa (README, CONTRIBUTING, CHANGELOG)
- 📜 Licença MIT

### Funcionalidades
- Cálculo preciso usando fórmula de escala temperada
- Interface profissional com tema corporativo (azul escuro/bronze)
- Validação de entrada
- Tratamento de erros
- Valores numéricos em monospace para melhor legibilidade
- Informações estruturadas com cards informativos

### Tecnologias
- **Frontend**: React 19, TypeScript, Vite, CSS3
- **Backend**: Clojure, Reitit, Ring, Jetty, Muuntaja, ring-cors
- **Dev**: Node.js 18+, Java 21+, Clojure CLI
